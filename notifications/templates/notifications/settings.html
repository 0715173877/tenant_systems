About Automated SMS

Beem Africa SMS Gateway is used to send automated reminders to tenants and guests.

What Gets Sent
  • Lease expiry — reminders when a lease is about to end
  • Rent due — reminders before rent payment is due
  • Check-in reminders — for upcoming guest bookings
Schedule

Automated tasks run daily via Celery Beat. Times configured here apply to when the task executes.

API Credentials

Configured via .env file: BEEM_API_KEY and BEEM_SECRET_KEY.
